# 🧠 DemeLens AI

### Dementia-Focused Multimodal Cognitive-Linguistic Analytics & Evidence-Grounded Caregiver Intelligence

**DemeLens AI** is a research-oriented, non-diagnostic AI platform designed specifically to study **dementia-related cognitive-linguistic change over time**.

Instead of treating dementia-related speech analysis as a one-time classification problem, DemeLens AI approaches it as a **longitudinal evidence problem**.

The platform combines:

**Speech Processing + NLP + Machine Learning + Explainable AI + Personal Baselines + Longitudinal Analytics + RAG + Evidence Provenance**

> **Change ≠ Diagnosis.**
>
> DemeLens AI does not diagnose dementia. It identifies and explains persistent changes in observed cognitive-linguistic patterns that may warrant further attention.

---

## 🔬 The Core Idea

A simple dementia speech project might do:

```text
Audio → Transcription → ML → Dementia Prediction
```

DemeLens AI goes further:

```text
SPEAK
  ↓
TRANSCRIBE
  ↓
ANALYZE
  ↓
BASELINE
  ↓
TRACK
  ↓
DETECT
  ↓
EXPLAIN
  ↓
RETRIEVE
  ↓
VERIFY
  ↓
UNDERSTAND
```

The central research question is:

> **Can longitudinal analysis of speech and language characteristics identify persistent dementia-related cognitive-linguistic changes while distinguishing meaningful patterns from temporary variation and insufficient data?**

# 🤖 3. Multi-Model ML Observatory

DemeLens does not rely on a single opaque model.

Candidate models include:

- Logistic Regression
- Random Forest
- XGBoost

The platform compares their analytical outputs.

Example:

| Model | Signal |
|---|---|
| Logistic Regression | Elevated |
| Random Forest | Elevated |
| XGBoost | Elevated |

### Model Agreement

```text
3 / 3 models aligned
Model Agreement: HIGH
```

If models disagree, that disagreement becomes part of the uncertainty analysis rather than being hidden.

# 🔎 4. Explainable AI with SHAP

DemeLens uses **SHAP** where appropriate to investigate which features contributed to a model's analytical signal.

Example:

```text
Major contributing markers

↓ Vocabulary Diversity
↑ Repetition
↓ Semantic Coherence
↑ Filler Frequency
↓ Syntactic Complexity
```

The interface communicates:

> "These features contributed to the model's analytical signal."

It does **not** claim:

> "These features prove dementia."

# 📈 5. Personal Cognitive-Language Baseline

One of DemeLens AI's core differentiators is that it does not rely solely on population averages.

The system establishes an individual's observed linguistic baseline from earlier observations.

Example:

```text
Week 1   → Baseline
Week 2   → Similar
Week 3   → Similar
Week 4   → Noticeable deviation
Week 5   → Persistent deviation
```

The system can therefore ask:

> **How has this person's speech changed relative to their own previous pattern?**

---

# 🧬 6. Personal Baseline vs Population Reference

These are intentionally kept separate.

### Personal Baseline

> What is normal for this individual?

### Population Reference

> How does this pattern compare with research datasets?

This distinction helps prevent population averages from being incorrectly treated as an individual's normal behavior.

---

# 🚨 7. Anomaly vs Persistent Trend

DemeLens explicitly distinguishes different longitudinal states.

```text
ISOLATED ANOMALY
       ↓
One unusual observation
       ↓
Not enough evidence


EMERGING SIGNAL
       ↓
Multiple observations show deviation
       ↓
Requires monitoring


PERSISTENT PATTERN
       ↓
Repeated deviation across observations
       ↓
Stronger analytical signal


INSUFFICIENT EVIDENCE
       ↓
Too little / poor-quality data
       ↓
No conclusion
```

# 🎯 8. First Signal Detector

### One of the project's major differentiators.

DemeLens identifies the earliest point at which a **meaningful and persistent deviation from an individual's baseline** becomes detectable.

Example:

```text
Week 1  ── Baseline
Week 2  ── Normal variation
Week 3  ── Mild deviation
Week 4  ── Deviation
Week 5  ── Persistent deviation detected
```

The system can highlight:

```text
FIRST PERSISTENT SIGNAL

Observation: #5

Reason:
Deviation was observed across multiple linguistic
markers and persisted across subsequent observations.
```

This is an analytical research visualization, **not a medical diagnosis**.

# 🕳️ 11. Missing Data Intelligence

DemeLens explicitly prevents missing observations from being interpreted as stability.

Example:

```text
Week 1 → Data
Week 2 → Data
Week 3 → Missing
Week 4 → Data
```

The system reports:

> **Insufficient observations during Week 3.**

It does **not** report:

> "No change."

This is important for reliable longitudinal analysis.

# 🔍 14. Hybrid Evidence Retrieval

DemeLens combines:

### Vector Retrieval

Semantic similarity between the query and evidence.

### BM25

Keyword-based retrieval.

### Cross-Encoder Reranking

Retrieved candidates are reranked according to query relevance.

```text
User Question
      ↓
 ┌────┴────┐
 ↓         ↓
BM25    Vector Search
 ↓         ↓
 └────┬────┘
      ↓
Candidate Evidence
      ↓
Cross-Encoder
      ↓
Evidence Selection
      ↓
LLM
```

---

# ⚔️ 15. Evidence Battle

A major RAG research feature.

DemeLens does not intentionally retrieve only evidence supporting an answer.

It also looks for **qualifying, conflicting, or limiting evidence**.

```text
              USER QUESTION
                    │
                    ↓
       ┌────────────────────────┐
       │   SUPPORTING EVIDENCE  │
       └────────────────────────┘
                    VS
       ┌────────────────────────┐
       │ QUALIFYING / CONFLICT  │
       │       EVIDENCE         │
       └────────────────────────┘
                    │
                    ↓
                SYNTHESIS
```

This helps reduce confirmation bias and makes the RAG system more evidence-aware.

# 🔐 Safety Philosophy

DemeLens AI follows strict analytical language boundaries.

### ✅ Allowed

> "Elevated dementia-related analytical signal."

> "Persistent deviation in linguistic markers was observed."

> "The model detected increased repetition relative to baseline."

> "Further professional evaluation may be appropriate."

### ❌ Not Allowed

> "You have dementia."

> "You definitely have Alzheimer's."

> "You are developing dementia."

> "Start this treatment."

> "Stop this medication."

The system is:

**Research-oriented + Non-diagnostic + Evidence-grounded + Uncertainty-aware**

---

# ⚠️ Medical & Research Disclaimer

DemeLens AI is an experimental research and decision-support prototype.

It is **not a medical diagnostic system**, and its outputs must not be interpreted as a diagnosis of dementia or Alzheimer's disease.

Analytical signals are based on computational analysis of observed speech and language patterns and may be influenced by factors including:

- Topic
- Fatigue
- Stress
- Environment
- Education
- Language background
- Recording quality
- Familiarity with the task
- Dataset limitations

Any real-world clinical interpretation requires appropriate professional evaluation.
